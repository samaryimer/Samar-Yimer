### 📊 Featured Projects

**🏥 [Hospital Financial Performance Analysis](https://github.com/[your-github-username]/data-analytics-portfolio/tree/main/hospital-financial-performance)**
Queried a multi-year hospital financials dataset in BigQuery (SQL) and built a dashboard tracking revenue, net income, and profitability by hospital size and ownership type across hundreds of U.S. hospitals. Found nonprofit hospitals outperform other ownership types on average revenue, and surfaced a sharp post-2022 spike in system-wide profitability.
`SQL` `BigQuery` `Dashboarding`

**🚑 [Emergency Room Wait Time Analysis](https://github.com/[your-github-username]/data-analytics-portfolio/tree/main/er-wait-time-analysis)**
Cleaned and analyzed 5,000 ER visit records across five hospitals in Python, using IQR-based outlier detection to flag unusually long waits. Found low-urgency patients waited ~174 minutes on average, with wait time strongly and negatively correlated with patient satisfaction — leading to a fast-track workflow recommendation.
`Python` `Pandas` `EDA`
